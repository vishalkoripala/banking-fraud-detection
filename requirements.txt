# Every version below is pinned EXACTLY, not with a floor (>=). This isn't
# stylistic -- model/fraud_model.joblib is a fitted scikit-learn object, and
# scikit-learn does not guarantee pickle compatibility across versions.
# A loose "scikit-learn>=1.3" constraint previously let installs drift to a
# different sklearn than the one that built the shipped model, which broke
# prediction with a cryptic 'LogisticRegression' object has no attribute
# 'multi_class' error -- fallout from multi_class being deprecated in 1.5
# and removed in a later release. Exact pins mean anyone installing this
# gets the identical environment the model was trained and tested in.
#
# If you ever see an AttributeError like that again: delete model/ and
# rerun `python train_final_model.py` so the model is rebuilt with
# whatever's actually installed, rather than assuming a version mismatch.
